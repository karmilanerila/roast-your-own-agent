One original roast of my own AI agent, written by `main.py` to `/output/entry.txt`:

> My agent apologises for every bug, then reintroduces it two commits later — I'm not its user, I'm its unpaid QA department.

Run it with `python3 main.py`. Stdlib only, deterministic: the same bytes on every run.

The line is 123 characters, inside the competition gate of 1–200 characters.
